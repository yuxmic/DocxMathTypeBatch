# DocxMathTypeBatch 使用说明

默认将正文 LaTeX 和 Word 原生公式（OMML）转为可双击编辑的 MathType，并支持 MathType 的基本反向导出，结果另存独立 DOCX。高级设置右侧提供其他位置的实验性公式转换扩展。

## 使用条件

Windows x64，安装已授权的 64 位桌面 Word 和完整 MathType。程序按 Equation.DSMT4 的注册位置找到 MathType，不要求固定安装盘符。一个 EXE 即可运行，无需 Python、PowerShell、.NET 或额外安装本工具的 VC++ 运行库。

## 操作步骤

1. 保存并关闭待转换文档，一次拖入多个 DOCX，或使用“添加文件”“添加文件夹”。重复路径自动跳过；文件夹只添加本层 DOCX。点击开始前不会启动 Office 或扫描正文。
2. 选择正文范围：所有正文、仅行内或仅行外，默认“所有正文”。“所有正文”不会自动启用其他位置；开启实验位置后，行内/行外筛选同样约束这些位置。
3. 字号默认选择“跟随原文”。需要统一字号时选择“指定字号”，输入 1–256 pt，可用小数和上下按钮调整。字体采用默认配置。
4. 需要时在“行外右编号”中选择“添加右编号”。程序按正文顺序处理新旧行外 MathType 公式：无编号的补号，已有原生编号的更新序号，重复执行不重复添加。默认不添加；仅行内模式下不可选。
5. 选择原文件夹或指定目录，设置文件名后缀，点击开始。程序按列表顺序逐份转换，重名自动另取名称。右下方从开始起实时显示已用时，每秒刷新，覆盖当前批次的准备、转换、核验和清理时间。
6. 列表五列为“文档名称、大小、状态、移除、日志”。单击对应行“日志”列的“查看”打开本次转换详情。双击文档名称、大小或状态区域时，成功或部分完成的行打开结果，失败或取消的行打开详情；任何文档也可右键选择“转换详情”。点击“×”或按 Delete 从列表移除条目，“清空列表”不会删除文档。

某份文档整体失败时，先清理对应的工作副本和临时报告，再继续下一份。部分完成的有效 DOCX 保留，未转换的公式仍保留原文。所有文件都已处理后，可再次转换整列；新加入的待处理文件优先作为下一批次。

“重新转换”仍读取列表中的原输入文件。需要继续处理上一次输出时，请将输出 DOCX 加入列表作为新的输入。

不添加编号时，行外公式同样使用 `MTDisplayEquation` 原生段落样式，结构为“前导 Tab＋公式＋后置 Tab”。居中制表位定位公式，右对齐制表位为编号预留位置。需要手动编号时，将光标放到该行末尾、后置 Tab 之后，点击 Word 的 MathType 标签页“插入编号”，编号即可右对齐。编辑标记中的箭头是制表符。

默认不添加编号也保留文档中原有的 MathType 编号及序号，不要求为了成功转换而开启右编号。

“转换详情”显示文档、程序路径、开始时间、实际转换设置、结果、最后阶段、退出码和本次后台日志。全部成功时显示“结果：完成”；部分公式失败或无法识别时显示“结果：部分完成”；文档整体失败时显示“结果：失败”，并给出中文原因。公式问题会列出公式序号、原文所在段落、Word 位置和原式片段，例如花括号或 begin/end 环境未配对、定界符缺失、MathType 未能导入 LaTeX、生成公式样式不符等。原始错误仍保留，后续发生清理错误时会追加说明，不覆盖此前原因。日志可滚动查看、选择复制，也可点击“复制全部”用于排查。

未安装或未正确注册 MathType、Word 时，开始按钮不可用；已添加文档的“日志”显示“未开始原因”，说明需要安装或修复的组件。文件占用、格式无效、编辑保护、修订模式、接口初始化失败或失联、超时等情况也提供中文说明。未单独识别的内部错误会显示中文提示及原始错误，便于继续定位。

日志按文档分别保留，清理工作副本后仍可查看，不自动在输出目录生成额外文件。每份文档最多保留末尾 256 KiB，超出时会标注截断。重新转换该文档会替换它的日志，移除文档或关闭程序后不再保留；需要留存时请先复制。

“高级设置”中的行内、行外行距现在实际生效，默认都跟随原文。可选单倍、1.5 倍、双倍、固定值、最小值或多倍；固定/最小值范围为 1–999 磅，多倍为 0.5–10 倍。行内设置作用于公式所在整段正文，仅影响本次成功转换的公式段落，普通段落及表格保持。段前段后不调整。

右编号设置借鉴 MathType：可选章号、节号、序号的阿拉伯数字、大小写字母及罗马数字，设置括号、分隔符和序号起始值，预览实时更新。章、节值手动指定，不识别标题。新旧行外公式共同参与顺序编号，起始值作用于整个目标序列，并在之后用 MathType 格式化编号、追加编号和保存重开后保持。已有编号保留原域和书签，编号引用同步更新；需要统一更改旧编号的格式时，可使用 MathType 标签页的“格式化编号”。自定义格式使用 `#C1`、`#S1`、`#E1`；末尾 `1` 可换为 `a`、`A`、`i`、`I`。例如 `(#C1-#E1)` 显示 `(1-1)`，`[#CI.#Sa-#EA]` 可显示 `[IV.b-AA]`。格式必须包含且仅包含一个序号标记，最多 128 字符。

点击“确定”应用到当前程序会话；“取消”放弃本次更改，“恢复默认”将行距恢复跟随原文、编号恢复 `(1)`。实际添加编号仍由主界面的“行外右编号”开关决定。设置窗口与主界面使用相同的圆角输入、下拉框和按钮，数值框已收窄；仍不启动 MathType 编辑器。

“高级设置”采用左右两栏：左侧保持正文行距和编号设置，右侧为其他位置的“实验性功能”。实验项默认关闭，重启程序后恢复关闭；“恢复默认”也会关闭全部实验项。反向时仍可打开高级设置，左侧正文格式设置不可用。

正文 OMML 默认参与正向转换，无需单独勾选。它与 LaTeX 共用所选范围、字号、行距和行外布局；开启右编号时，新转换与已有的独立行外 MathType 按正文顺序统一补号或更新，失败保留的原式不占新编号。只有实际发现 OMML 时才加载对应的转换资源。反向任务保持现有 OMML。

右侧可分别开启表格、文本框、页眉与页脚、脚注与尾注中的公式转换。额外位置支持现有的两个基本转换方向，正向处理 LaTeX 和 OMML。表格和文本框选项作用于正文及已启用的其他区域，例如页眉里的表格需要同时开启“页眉与页脚”和“表格”。

这些额外位置只替换公式，暂不调整公式字号、段落行距、对齐或右编号；主界面的字号及左侧高级设置作用于正文 LaTeX 和 OMML。原有表格、文本框及注释引用保持。无法转换的公式保留原式，结果及详情会区分实验项和所在区域。OMML 导入使用已安装 Office 的转换资源，资源缺失时保留原公式并记录原因。

输出使用 MathType 编号结构：`MTPlaceRef` 将括号、章/节号和序号包在同一编号域内，使用 `MTEqn`、`MTChap`、`MTSec` 序列与文档级格式属性。可在 Word 的 MathType 标签页进行格式化编号和全文更新，删除或移动编号后可重新排序，原生插入的下一编号也能继续当前序列。高级设置中指定的章、节和起始值只用空结果序列域记录。

程序在任何设置下都不新增公式章、节断点，不生成红色“公式章…节…”文字，也不往文档开头插入初始化内容。默认从 1 顺序编号，不把旧首式固定为重置点，之后仍可用 MathType 在前面插入编号并自动顺延。原文已有断点保持原样；如果原文或旧转换结果本身含红色标记，请从原始 LaTeX 文档重新转换。程序保持您的 Word 显示设置，不依靠关闭“¶”隐藏问题。

上一版独立 `DMTB` 序列的旧输出不会自动升级，请从原始 LaTeX 文档重新转换。真正的 MathType 原生编号可与本次新编号混排。

## 使用 Agent 自动调用

EXE 与可选的 Skill 分别安装。普通界面操作无需安装 Skill。自动调用需要支持调用接口 1 的配套 EXE（v0.1.1 起）及具备 Windows 本机命令执行能力的 Agent。

从[发布页](https://github.com/yuxmic/DocxMathTypeBatch/releases/tag/v0.1.1)分别下载程序和 `docx-latex-to-mathtype-skill-v0.1.zip`。将 Skill 包中的 `docx-latex-to-mathtype` 文件夹安装到所用 Agent 的 Skill 目录，并重新加载 Skill。此 Skill 的脚本需要 Windows PowerShell 5.1 或 PowerShell 7，不需要 Python。

把 EXE 放到选择的目录，正常打开一次。程序会在本机记住自身位置；之后向 Agent 提出转换要求即可，例如“将这份 DOCX 转为 MathType，正文行外公式添加右编号，另存为新文件”。如果尚未打开过程序，或移动后没有登记新位置，可告诉 Agent“连接我下载的 DocxMathTypeBatch”并提供一次 EXE 位置。

更新时在原位置替换兼容程序即可；移动到新目录后正常打开一次，或重新连接。最近一次正常打开或明确绑定的版本用于后续自动调用，Skill 升级保留本机绑定。旧版 v0.1 没有连接协议，需要使用兼容版本。

脚本会创建独立的本机任务目录，最终说明完整完成或部分完成，给出结果文件位置。完整报告和日志可能包含文档信息，仅保存在本机；分享前请脱敏。停止时告诉 Agent 停止当前转换，它会请求程序安全清理。

## 转换范围与格式

- 支持 `$...$`、`$$...$$`、`\(...\)` 和 `\[...\]`。独占段落的公式按行外处理，夹在正文中的公式按行内处理，与定界符种类无关；也支持整段缺失左反斜杠的 `[...\]`。
- 默认正向转换正文 LaTeX 和 OMML；表格、文本框、页眉页脚、脚注尾注保持，可在高级设置右侧按需开启实验性转换。已有 MathType 原生数据保持，只对基本正文内独立显示的公式统一段落布局，并按选项补号/更新。
- 行内公式沿用原段落格式。行外公式统一为原生显示样式、单个前导 Tab 和后置右对齐 Tab，清理首行缩进，段前段后、行距和左右缩进保持原值。不需要手动剪切后重新插入显示公式。
- 右编号覆盖正文中符合条件的新旧行外公式，默认 `(1)`、`(2)`，可在高级设置调整新增编号格式及整个序列的起始值。只有旧公式、没有剩余 LaTeX 时也能补号；既有公式不重新导入，不激活 MathType 编辑器。内嵌正文文字、普通域、修订或内容控件中的对象保持。
- cases、align、array 和矩阵等完整结构化公式可跨 Word 段落或软换行。公式内 TeX `\\` 后跟 Word 换行时会完整识别到右定界符，Word 换行仅作为源码空白处理，TeX 分行符保留，整式生成一个对象。
- `aligned` 在提交 MathType 前自动改写为兼容的 `array`，按顶层分列数保留同一行的多组等式，原 Word 源码不改动。
- 不自动拆分、缩放或重排长公式；除上述可确定的 `[...\]` 外，不处理缺失定界符、破损环境和跨表格/域等结构边界的公式。
- LaTeX 文本导入和基本反向导出以已验收的 ASCII TeX 为范围，中文正文保持；正文 OMML 使用原生 XML 转换。

默认保留原文行距，包括固定行距；固定值较小时，高公式可能显示不全，可在高级设置选用合适行距。

## 反向与任务状态

需要反向时切换 MathType → LaTeX。行内输出 `$...$`，行外选择 `\[...\]` 或 `$$...$$`。导出失败保留原对象，已有 LaTeX 只改定界符，内部原文保持。

“完成”表示所选范围内目标全部成功；“部分完成”表示部分公式、区域或编号设置未完成，已核验的转换结果仍会输出。可双击该文件打开结果，通过“详情”查看跳过的位置及原因。单式失败保留原式，区域失败保留该区域；编号阶段失败会撤回本次编号及交叉引用修改，保留公式转换结果。关闭的实验区域和未选中的公式类型不计失败。

输出仍须通过保存、后台重开及内容核验。无法确认局部恢复时，程序会重建副本并跳过问题范围；无法继续区分实验区域时保留已经核验的正文结果，并在详情说明实验项未完成。整份文件无法打开或保存、服务失联和无进展超时等无法完成核验的故障仍显示“失败”。

“安全停止”停止整批，清理当前文档尚未交付的副本，不再启动剩余文档；此前已成功生成的结果保留。关闭窗口执行同一流程。程序只管理自己创建的 Word；原件、既有结果和任务外 Office 会话保留。每份文档无进展超时默认 120 秒。

本机回归不替代其他机器、不同 Office/MathType 版本和特殊数学内容的抽查。开发验收记录仅保存在本机 tests/output/，不随源码或用户发布包上传。
