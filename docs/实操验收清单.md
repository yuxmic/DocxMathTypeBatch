# 实操验收清单

本表记录当前正文转换工具的人工检查，不用历史结果预先勾选。

| 项目 | 检查内容 | 结果 |
| --- | --- | --- |
| 正向与可编辑性 | 行内、行外、分段函数和已有 MathType；新对象可双击编辑，原件保持 | 待填 |
| 反向导出 | 公式内容、定界符、编号与周围文字符合设置 | 待填 |
| 范围保持 | 表格、文本框和其他故事保持，未选中的公式类型保持 | 待填 |
| 高级设置 | 字号、行距、右编号格式和起始值生效 | 待填 |
| 文件与队列 | 拖放、多选、重名避让、失败后继续、逐文档日志对应 | 待填 |
| 取消与关闭 | 当前任务清理、后续任务停止、此前成功结果及任务外会话保持 | 待填 |
| 显示缩放 | 不同显示器和缩放下控件、文字与焦点清晰完整 | 待填 |
| 安装发现 | 非默认安装位置和其他版本下检测、正反向及重开正常 | 待填 |

公开验收使用合成样本。使用个人文档人工检查时，文档、截图和记录只留在本机 `.local/`，不要填写进此公开清单。私人信息和实际文件路径不得进入提交。
