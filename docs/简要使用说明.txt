功能：
默认识别docx正文中含latex定界符的文本公式及Word原生公式（OMML），共同按指定范围、字号、间距、右编号转换，默认输出到原文件同目录；
转换成功会生成新的转换后的docx文件，原文件不改动；
少量公式或实验区域失败时保留原内容，其他区域正常转换，文件状态显示“部分完成”，可打开结果并通过日志查看跳过的位置；编号阶段失败会撤回本次编号修改，保留公式转换结果；
转换失败或手动终止均会清理残留文件，多文件转换会跳过失败的文件；
可点击“日志”查看结果和中文失败原因；公式问题会显示序号、原文段落、原式片段及具体原因，原始错误仍保留以便排查。

使用方法：
拖入或选中一个或多个文件或文件夹，按照偏好进行设置（默认“所有正文”、字号和行距跟随原文、不添加右编号）并转换。

正文OMML默认参与正向转换，不需要额外开关，与LaTeX及已有行外MathType按正文顺序统一编号。反向转换保持原有OMML。
高级设置右侧提供默认关闭的实验项：表格、文本框、页眉页脚、脚注尾注中的公式转换。这些位置只替换公式，不应用字号、段落或右编号设置；仅在当前会话中保留勾选状态。

AI 自动调用（可选）：
EXE v0.1.1 支持独立安装的 docx-latex-to-mathtype Skill v0.1。
正常打开 EXE 一次即可在本机登记程序位置，再由 Skill 的标准脚本调用；也可向 Agent 提供一次 EXE 位置完成连接。
移动程序后重新打开一次，或让 Agent 重新连接。用户路径仅保存到本机设置，不写入 Skill。
Agent 必须能在装有 Word/MathType 的 Windows 本机执行脚本；普通界面用户无需安装 Skill。
