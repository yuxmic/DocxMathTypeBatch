DocxMathTypeBatch v0.1.5
Word / LaTeX 批量转 MathType · 中文图形界面（GUI）

无需编程，拖入一个或多个 DOCX，即可将正文 LaTeX 和 Word 原生公式批量转为可双击编辑的 MathType。初次使用可直接按默认设置转换，也可按需设置字号、行距、转换范围和行外右编号。另提供完整 Agent Skill，支持用自然语言要求本机 Agent 转换。

运行条件
Windows 10（1703 及以上版本）或 Windows 11，均为 x64，已安装并正确注册的 64 位桌面 Microsoft Word 和完整 MathType。图形界面程序解压即用，无需 Python、PowerShell、.NET 或额外安装本工具的 VC++ 运行库。

下载与首次使用
1. 从 GitHub 发布页 https://github.com/yuxmic/DocxMathTypeBatch/releases/latest 下载 Windows x64 ZIP 程序包，解压后双击 DocxMathTypeBatch.exe。
2. 保存并关闭待转换文档，拖入一个或多个 DOCX，也可点击“添加文件”或“添加文件夹”。
3. 点击“开始转换”，完成后双击列表中的文档打开结果。输出为新文件，原文件保留。

默认使用标准模式，转换“所有正文”，字号和行距跟随原文，不添加右编号。需要统一格式时再调整主界面和“高级设置”中的选项。

功能
默认识别docx正文中含latex定界符的文本公式及Word原生公式（OMML），共同按指定范围、字号、间距、右编号转换，默认输出到原文件同目录；
转换成功会生成新的转换后的docx文件，原文件不改动；
少量公式或实验区域失败时保留原内容，其他区域正常转换，文件状态显示“部分完成”，可打开结果并通过日志查看跳过的位置；编号阶段失败会撤回本次编号修改，保留公式转换结果；
转换失败或在程序内停止时会清理临时文件，多文件转换会跳过失败的文件；外部强杀或断电可能留下临时文件；
可点击“日志”优先查看问题摘要：原文页码、原式片段、中文原因及修改建议。页码按转换前原文从首页连续计数（含封面）；页眉页脚等共用区域按节标识，无法取得页码时明确说明。点击“原始日志”查看段落、Word位置、设置及底层错误，“复制全部”复制当前视图。
常规正向转换会单独提醒本次公式可能超宽或在固定行距下显示不全，不自动改变版式、不记为转换失败。超宽检查限正文独占段落的行外公式，支持单栏及等宽分栏；实验区域可检查段落固定行距，暂不检查其容器宽高。快速模式不进行版式检查。

标准模式保留完整核验、失败恢复和保存重开检查。
快速模式提供通用转换能力，跳过完整核验，单式失败后尽量继续；输出需自行检查。
极速模式不启动 Word，直接转换正文普通段落中行内、行外的 LaTeX 和 OMML，支持同段多式及连续文本片段之间的 LaTeX，统一指定字号；独立行外公式可选单节单栏、从 1 开始且无旧编号的默认右编号。不核验、不重试、不自动降级，单式生成失败保留原式。表格、文本框、页眉页脚、脚注尾注及已有 MathType 保持，不计入转换目标；复杂编号、引用更新、额外排版和反向不在极速范围内。
普通段落仅含一个公式、手动尾号及空白时，极速会按行外处理，并在转换成功后清理旧号和多余空格、Tab；不开启右编号也会清理。支持 (27)、（27）、(3-2)、(3.2) 等数字编号。转换失败时原式和旧号保留；带正文、单位说明、多公式、域或内容控件的段落不清理旧号。
三种模式都拒绝开启修订或限制编辑的文件，原件另存、重名避让及取消继续生效。

标准和快速档的高级设置中，“转换 Word 原生公式（OMML）”默认开启，正文OMML与LaTeX共同转换并参与格式和编号。关闭后，正文及启用额外位置中的OMML保留，只转换LaTeX；主动保留不计为失败。反向始终保留OMML，此选项置灰。极速固定转换正文 LaTeX 和 OMML，高级设置不生效。选择仅在当前程序会话中保持。
独立正文 LaTeX 或原生公式后面的“（27）”“(3-2)”等手动数字编号与多余空白自动清除，公式按行外布局居中；新编号由“添加右编号”设置决定。正文说明、单位及域或控件边界保持。
高级设置右侧提供默认关闭的实验项：表格、文本框、页眉页脚、脚注尾注中的公式转换。这些位置只替换公式，不应用字号、段落或右编号设置；仅在当前会话中保留勾选状态。
首页“转换模式”提供标准／快速／极速三级滑块，可用鼠标或键盘方向键切换，默认标准，运行时不能切换。极速固定选择所有正文和指定字号，保留字号输入及行外右编号；显示实际公式计数，最多每 150 毫秒更新进度。高级设置禁用，切回其他档恢复原范围及字号方式。快速和极速结果均标记未经核验；重启或恢复默认回到标准。

实测速度
同一台电脑使用 v0.1.5 发布后的开发构建，固定 12 磅、开启进度和默认右编号，每份样本在三档各测一轮。用时含启动、转换、编号、保存和退出清理。
1,000 式合成 LaTeX 文本（361 行内／639 行外），标准 256.50 秒，快速 144.60 秒，极速 29.63 秒。
1,015 式真实含图 OMML（366 行内／649 行外），标准 500.77 秒，快速 331.71 秒，极速 43.70 秒。
详细设置和核对记录见 https://github.com/yuxmic/DocxMathTypeBatch/blob/main/docs/实测报告.md

v0.1.5 更新：
新增标准／快速／极速三档滑块；极速直接转换正文行内／行外 LaTeX 和 OMML，不启动 Word，支持指定字号、简单右编号和手动尾号清理。
优化 OMML 导入和编号处理，修复范数括号、关系分隔符及只读工作副本问题，增加阶段与耗时展示。
配套 Skill v0.2.2 内置 v0.1.5 EXE，支持标准、快速和极速，调用接口为版本 1。

v0.1.4 更新：
新增原文页码、问题公式片段、中文原因及建议摘要，可切换原始日志；新增默认开启的 OMML 转换开关。
常规正向转换单列有限范围的版式提醒，不改变转换成功状态；固定行距下是否裁切仅作疑似提示，快速输出仍未经核验。
复用 OMML 转换资源和已核验快照，减少重复读取；配套 Skill v0.2.1 通过无界面后台入口输出 AI 可用的计数与问题摘要。

v0.1.3 更新：
新增快速转换开关和配套 Skill 参数，默认关闭；修复快速模式与页眉页脚一起启用时的文件占用冲突。
复用正文快照及 OMML XML，减少重复资产复制和只读扫描的集合数量读取；常规模式保留核验与恢复。
优化开关外观、点击范围和切换动画；实验区只保留四个位置选项，补充分项退出、清理计时。

v0.1.2 更新：
后台转换移除向 Word 注入 DLL 的实现，并在任务 Word 争取前台时及时交还最近使用的窗口。
转换期间允许熄屏和锁屏，阻止空闲自动睡眠；手动睡眠期间暂停，唤醒后继续，睡眠时间不计入无进展超时。
增加常见 LaTeX 命令与多行结构的自动兼容，修复原生公式空格、嵌入附件和反向百分号等问题。
2026-10-28 本地修订：修复 Word 原生公式中 Ŷ、组合帽符号及横线等顶饰的导入，支持 Unicode 字母顶饰和叠加顶饰，补充 \widetilde、\mathring 兼容写法。
本次保持原有缓存回显和成功判定；宽顶饰的 PDF 渲染及既有反向导出限制仍需检查结果。

AI 自动调用（可选）：
docx-latex-to-mathtype Skill v0.2.2 内含 v0.1.5 EXE，Agent 用户只安装完整 Skill 包即可。默认标准模式，可明确指定快速或极速。
使用极速时请指定字号。例如「用极速模式转换这份 DOCX 的正文公式，字号 12 磅，行外添加默认右编号，另存为新文件。」极速输出需要检查。
脚本直接使用包内 bin/DocxMathTypeBatch.exe，无需另行下载转换器、打开 GUI 或登记路径。
整个 Skill 目录移动后仍可使用；升级时替换完整包。普通 GUI 用户继续使用单独的程序包。
Agent 必须能在装有 Word/MathType 的 Windows 本机执行脚本；普通界面用户无需安装 Skill。
